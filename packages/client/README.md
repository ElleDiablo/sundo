# @sundo/client

The browser game: Phaser 4 + Vite (ADR-0008). Game rules live in `@sundo/engine`; this package
reads the keyboard and draws.

```
npm run dev -w @sundo/client       # http://localhost:5173
npm run build -w @sundo/client     # production build in dist/ (deployed by CI)
npm run assets -w @sundo/client    # regenerate art (add -- --force to also regenerate the map)
```

## Editing the map in Tiled

Open `public/assets/maps/barangay.tmj` in Tiled. Save, then refresh the browser.

| Layer | What goes on it | Drawn |
|---|---|---|
| `ground` | grass, paths, water, dikes, plaza, bridges | under everything |
| `decor` | tufts, flowers, pebbles, leaves, puddles | on the ground |
| `objects` | the lower part of things: walls, stilts, trunks, fences, stalk bases | under the player |
| `above` | the upper part: roofs, tree canopies, bamboo tops, the lamp head | over the player |
| `lights` | points where a warm glow is drawn (doorways, windows) | over the night tint |
| `spawns` | the point named `player` | not drawn |

- **Solid tiles:** a tile blocks movement when its tileset entry has `collides = true`
  (walls, roofs' bottom rows, trunks, fences, bamboo bases, water). The engine reads this, so
  painting a tile is enough; there is no separate collision layer.
- **Multi-tile objects:** in the Tilesets panel, drag to select the whole object (e.g. the 7×6
  bahay kubo) and stamp it. Put its top rows (roof, canopy) on `above` and the rest on `objects`,
  so characters walk behind roofs and in front of walls.
- The map is fixed on purpose: the tikbalang's nightly heat maps only mean something if every
  round is played on the same map (GDD §4). Only the decoration is scattered by a seed.

## Art

All art is generated by `scripts/make-assets.ts` in the style of the art direction prototype.
The tanod sprite comes from my own character sheet (`scripts/sprites/tanod.json`, palette + rows);
the 4-frame walk is generated from that single pose. The night tint and doorway glows are a
stand-in until real lighting (S3-01).
